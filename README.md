# Computer Vision & Data Preprocessing for Diffusion Models

Репозиторий содержит модули предобработки данных, сегментации изображений и генерации масок, разработанные для пайплайна диффузионного редактирования (Inpainting / Object Removal), а также классические DL-модели.

#1. Модуль кластеризации и подготовки масок для Inpainting / Diffusion
* **Файлы:** `clastfordif1.0.ipynb`, `clastfordif1.1.ipynb`
* **Стек:** `Python`, `OpenCV`, `NumPy`
* **Назначение:** Алгоритмическая подготовка изображений и масок перед подачей в диффузионную модель для удаления целевых объектов.
* **Что реализовано:**
  * Поиск и кластеризация целевых областей с использованием метода связных компонент (`cv2.connectedComponentsWithStats`).
  * Автоматическое выделение и закрашивание ненужных объектов на основе геометрии (площадь, центроиды).
  * Фильтрация шума и форматирование масок под входные требования генеративных архитектур.
  * Пакетная (batch) обработка папок с изображениями для автоматической подготовки датасета.

#2. Сверточная нейросеть для классификации (CNN CIFAR-10)
* **Файл:** `easycompvis.ipynb`
* **Стек:** `Python`, `TensorFlow / Keras`, `Matplotlib`
* **Назначение:** Лабораторная работа по классическому компьютерному зрению и Deep Learning.
* **Что реализовано:**
  * Архитектура Deep CNN для распознавания 10 классов объектов датасета CIFAR-10.
  * Применение техник регуляризации (`Dropout`, `MaxPooling`) и оптимизатора SGD с моментом Nesterov (`momentum=0.9`).
  * Построение графиков сходимости модели (`Loss` и `Accuracy`).
